# Mining Run

A Roblox game project maintained inside this repository, isolated from the existing Motion Studio application.

## Project workspace

- `CLAUDE.md`: implementation instructions for Claude Code.
- `docs/GAME_DESIGN.md`: approved gameplay direction and open design decisions.
- `docs/DEVELOPMENT_STATUS.md`: current phase, progress, and next actions.
- `references/`: visual references and sketches. Existing reference images currently remain at the repository root; do not move or duplicate them without approval.
- `game/`: Roblox game source and project files. Implementation has not started.

## Working agreement

- The Game Director (user) owns gameplay and visual decisions.
- ChatGPT acts as Technical Director: planning, architecture review, coordination, and validation.
- Claude Code owns implementation, integration, automated testing, debugging, and regression checks.
- Both AIs must use this directory and its documents as the shared source of truth.
- Do not modify files outside `Mining-Run/` for this project.
- Do not publish the Roblox experience or perform destructive repository operations without explicit approval.
